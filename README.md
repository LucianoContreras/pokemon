# Tienda Pokémon

Pagina web principalmente enfocada en una tienda de items de Pokémon.

##  Tecnologías Utilizadas

Este desarrollo inicial está construido con las siguientes herramientas y librerías:

1. **HTML5:** Estructura semántica de la página web.
2. **CSS3:** Estilos personalizados, diseño responsivo y adaptación visual.
3. **JavaScript:** Lógica de interacción, dinamismo del catálogo y gestión del carrito de compras.
4. **Materialize CSS:** Framework de diseño frontend basado en las directrices de *Material Design* para una interfaz limpia, moderna y fluida.

##  Características Principales

* **Catálogo Variado:** Visualización de diferentes items clásicos del universo Pokémon.
* **Diseño Responsivo:** Adaptable a dispositivos móviles, tablets y computadoras de escritorio gracias a Materialize.
* **Interfaz Interactiva:** Componentes dinámicos impulsados por JavaScript para mejorar la experiencia de usuario.
